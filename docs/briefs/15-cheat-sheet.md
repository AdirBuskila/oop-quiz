# דף עזר: C++ למבחן אמריקאי

> 🔑 **דף אחד לפני המבחן.** הכללים שחוזרים בכל מועד, בסדר שבו כדאי לבדוק אותם. כל כלל מפנה לפרק שבו יש הסבר ודוגמה שהורצה.

## תוכנית תקיפה לכל שאלה

1. **קומפילציה קודם.** הפניה בלי אתחול, השמה ל-`const`, קריאה עמומה, גישה לפרטי, יצירת מחלקה מופשטת, שדה const/הפניה בלי אתחול. אם יש שגיאה, התשובה "לא מתקמפל" או ספירת שורות.
2. **הרשאות.** מי קורא ומה ההרשאה בטבלת הירושה.
3. **העתקות וחיים.** מי נקרא בכל שורה: בנאי, העתקה, השמה, הורס.
4. **דינמי או סטטי.** `virtual` דרך מצביע/הפניה.
5. **טבלה קטנה.** אם הפלט תלוי בסדר או במשתנה סטטי, כותבים טבלה, לא מנחשים.

(בשאלות "מה מדפיסה" קוראים את הפלט שבתשובה משמאל לימין. בקוד המבחנים כתוב `void main()`: מקבלים אותו כנתון.)

## הרשאות ([[inheritance_access]])

| הרשאה באב | ירושה public | ירושה protected | ירושה private |
|---|---|---|---|
| public | public | protected | private |
| protected | protected | protected | private |
| private | לא נגיש | לא נגיש | לא נגיש |

- `friend`: חד-כיווני, לא עובר בירושה, פונקציה אחת בלבד לכל עומס ([[friend_this_static]]).
- ברירת מחדל: `class` פרטי, `struct` ציבורי.

## בנייה והריסה ([[construction_order]])

| מה | סדר |
|---|---|
| בנייה | אבות לפי רשימת הירושה, שדות לפי הצהרה, גוף |
| הריסה | הפוך לבנייה |
| גלובלי | לפני `main`, נהרס אחרון |
| סטטי מקומי | בפעם הראשונה בלבד, נהרס בסוף התכנית |
| זמני | נהרס בסוף הביטוי (אלא אם קשור ל-`const T&`) |
| `new` | הורס רק ב-`delete` |
| קריאה וירטואלית בבנאי/הורס | הגרסה של הסוג שנבנה כעת |

## העתקה ([[copy_control]])

| שורה | מה נקרא |
|---|---|
| `T b = a;` `T b(a);` | בנאי העתקה |
| `b = a;` | אופרטור השמה |
| פרמטר בערך | בנאי העתקה (+ הורס בסוף) |
| החזרה בערך | העתקה, או כלום (C++17 מבטל זמני) |
| `T(T t)` | אסור |
| `T(const T&)` | הצורה היחידה לבנאי העתקה |

מצביע בשדה => חוק השלושה: הורס, בנאי העתקה, `T& operator=(const T&)`.

## const והפניות ([[const_references]])

| הצהרה | אסור | מותר |
|---|---|---|
| `const int* p` | `*p = 1` | `p = &x` |
| `int* const p` | `p = &x` | `*p = 1` |
| `void f() const` | לשנות שדות | לקרוא לה על אובייקט const |

- שדה `const` והפניה: באתחול ברשימה, בכל בנאי.
- `T&` לא נקשר לזמני; `const T&` כן.
- `this` בפונקציה const הוא `const X*`.

## הפניות והעמסה ([[cpp_basics_refs]])

- הפניה: אתחול חובה, אי אפשר להפנות מחדש.
- ערכי ברירת מחדל מימין; עמימות כשהקריאה מתאימה לשתיים.
- העמסה לפי פרמטרים בלבד, לא לפי טיפוס החזרה.
- `f() = 5` מחייב טיפוס החזרה `T&`.

## אופרטורים והמרות ([[operator_overloading]], [[operator_conversions]])

- אופרנד שמאלי מחוץ למחלקה (`2 + x`, `cout << x`) => פונקציה חיצונית.
- `++x`: `operator++()`; `x++`: `operator++(int)`.
- `<<`: `ostream& operator<<(ostream&, const X&)`.
- `=`, `[]`, `()`, `->` חייבים להיות חברים.
- `X x = 5` => בנאי עם `int`; `int n = x` => `operator int()`; `explicit` חוסם המרה אוטומטית של בנאי; לכל היותר המרה אחת מוגדרת-משתמש.

## וירטואליות ([[virtual_polymorphism]], [[abstract_multiple]])

- דינמי רק דרך מצביע/הפניה ורק אם `virtual` באב. אובייקט בערך => סטטי (חיתוך).
- אותה חתימה (כולל `const`) => דריסה; אחרת פונקציה חדשה.
- ערכי ברירת מחדל נקבעים לפי הטיפוס המוצהר.
- `= 0` => מופשטת: אין אובייקטים; נגזרת שלא דרסה הכול נשארת מופשטת.
- יהלום: שני עותקים של הבסיס; `virtual` בירושה => אחד. `d.x` עמום, `d.B::x` תקין.
- `delete` דרך מצביע לאב דורש הורס וירטואלי.
- `dynamic_cast`: דורש פולימורפיות, `nullptr` בכישלון (הפניה: `bad_cast`).

## תבניות ([[templates]])

- שדה סטטי: עותק לכל הצבה; משתנה גלובלי משותף לכולן.
- פרמטרי הפונקציה מאותו `T` חייבים להסיק טיפוס זהה; `f<double>(...)` מכריח.
- פונקציה רגילה מתאימה מנצחת תבנית; `X<>` לתבנית עם ברירות מחדל.
- מימוש חיצוני: `template <class T> void abc<T>::f() {}`.

## STL וחריגות ([[stl_exceptions]])

- `end()` אחרי האחרון; ריק => `begin() == end()`.
- `insert(it, x)` לפני `it`; `*(it++)` הערך הישן.
- איטרטור של `vector` תומך ב-`<` ובחיבור; של `list` לא.
- `catch` הראשון שמתאים; `catch(...)` תופס הכול; הורסים רצים בזמן הפירוק.

## מלכודות שחוזרות

> 🪤 `X b();` היא הצהרת פונקציה. `T b = a;` היא העתקה ולא השמה. בנאי כלשהו מבטל בנאי ברירת מחדל.

> 🪤 רשימת האתחול לא קובעת סדר. סטטי מקומי נבנה פעם אחת.

> 🪤 פונקציה בנגזרת מסתירה את כל ההעמסות של האב. חיתוך מאבד את הסוג האמיתי.

> 🪤 מפתחות מבחנים ישנים נכתבו לפני C++17 (למשל ביטול העתקה בהחזרה). כשהשאלה אומרת "בהכרח" אל תספרו העתקות שמותר לבטל.
