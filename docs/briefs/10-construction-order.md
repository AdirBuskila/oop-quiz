# סדר בנייה והריסה

> 🔑 **בשורה אחת:** בבנייה: אבות (לפי סדר ברשימת הירושה), אחר כך שדות (לפי סדר ההצהרה), ובסוף גוף הבנאי. הריסה בדיוק הפוך. גלובליים נבנים לפני `main`, סטטיים מקומיים בפעם הראשונה שמגיעים אליהם, וכולם נהרסים בסדר הפוך לסדר שבו **הושלמה** בנייתם.

## מה המבחן שואל

הנושא הנפוץ ביותר בשאלות "מה מדפיסה התכנית":

- אב ונגזרת עם הדפסות בבנאי ובהורס: `1342` (18A-A שאלה 11, `25S-A-Q5`, `25S-A-Q6`).
- `new Y` בלי `delete` (רק `13`), ו-`delete` דרך מצביע לאב (`132` בלי virtual, `1342` עם virtual) (18A-A שאלה 16, 18A-B שאלה 14).
- משתנה גלובלי, מקומי וסטטי: `static X a(1); X b(2); X c(3);` נהרסים `321` (18A-A שאלה 3), גלובלי `X a(1)` ומקומי באותו שם (18A-B שאלה 3), סידור מלא של גלובלי, פונקציה, סטטי (19A-A שאלה 7, 19A-A שאלה 13, 23B-B שאלה 13, 23S-A שאלה 11).
- אב בעל כמה בנאים והורסים (19A-A שאלה 16, 19A-B שאלה 14): איזה בנאי של האב נקרא כשלא כותבים כלום (בנאי ברירת מחדל).
- בנאי של אב ושל שדה יחד, כולל השמה בגוף (22B-A שאלות 7 ו-11), גלובלי עם אב ושדה (22S-B שאלה 8), הדפסות של בנאי העתקה בנגזרת (22S-B שאלות 2, 4, 11).
- `One` ו-`Two`: הבנאי של האב מאתחל את `one` לפני שהנגזרת מאתחלת את `two` (21B-B שאלה 8).
- לחשב מה נקרא כשבונים מערך: `A arr[3]` ו-`new B[2]` (22S-B שאלות 2 ו-4).

## הגדרות

- **סדר בנייה לאובייקט:** (1) מחלקות אב לפי סדר ברשימת הירושה (`D : B1, B2` => `B1` ואז `B2`), (2) שדות לפי סדר ההצהרה במחלקה, (3) גוף הבנאי.
- **אב וירטואלי** נבנה לפני כל האבות הרגילים, על ידי המחלקה היורשת ביותר.
- **סדר הריסה:** גוף ההורס, שדות בסדר הפוך, אבות בסדר הפוך.
- **בנאי האב:** אם לא כתבתם אותו ברשימת האתחול נקרא בנאי ברירת המחדל שלו; אם אין כזה, שגיאה.
- **משתנים:** גלובליים נבנים לפי סדר ההגדרה בקובץ, לפני `main`. מקומיים נבנים כשמגיעים לשורה, נהרסים בסוף הבלוק בסדר הפוך. סטטי מקומי נבנה פעם אחת, בפעם הראשונה שהביצוע מגיע לשורתו, ונהרס בסוף התכנית.
- **הרס גלובליים וסטטיים:** בסוף התכנית, בסדר הפוך לסדר סיום הבנייה שלהם (גלובלי, סטטי ואחרון שנבנה = ראשון שנהרס).
- **זמני:** נהרס בסוף הביטוי. הפניה `const T&` שקושרת זמני מאריכה את חייו.
- **בנאי/הורס וקריאה וירטואלית:** בתוך בנאי או הורס של `B` קריאה לפונקציה וירטואלית מבצעת את הגרסה של `B`, גם אם האובייקט בפועל `D`.

## מתכונים

1. רושמים רשימה של כל האובייקטים בתכנית לפי סדר הבנייה: גלובליים (לפי סדר הקובץ), ואז מה שקורה ב-`main` שורה אחרי שורה. לכל אובייקט: אבות, שדות, גוף.
2. לכל פונקציה שנקראת: אותו עיקרון. סטטי מקומי נכנס לרשימה **רק** בקריאה הראשונה.
3. הריסה: מהסוף להתחלה. מקומיים בסוף הבלוק, ואחריהם גלובליים/סטטיים בסדר הפוך לבנייה (סטטי מקומי נבנה אחרי הגלובלי ולכן נהרס לפניו).
4. אובייקט ב-`new`: נהרס רק ב-`delete`; דרך מצביע לאב ההורס של הנגזרת רץ רק אם ההורס של האב `virtual`.

## דוגמה

אב, שדות וגוף:

```cpp
#include <iostream>
using namespace std;

struct Base1 { Base1() { cout << "Base1 "; } ~Base1() { cout << "~Base1 "; } };
struct Base2 { Base2() { cout << "Base2 "; } ~Base2() { cout << "~Base2 "; } };
struct M1 { M1() { cout << "M1 "; } ~M1() { cout << "~M1 "; } };
struct M2 { M2() { cout << "M2 "; } ~M2() { cout << "~M2 "; } };
struct D : Base1, Base2 {             // bases in the order of the inheritance list
    M2 m2;                            // members in the order of declaration
    M1 m1;
    D() : m1(), m2(), Base2(), Base1() { cout << "D "; }   // the written order is ignored
    ~D() { cout << "~D "; }
};
int main() {
    D d;
    cout << "\n";
}
```

```text
Base1 Base2 M2 M1 D 
~D ~M1 ~M2 ~Base2 ~Base1 
```

הבסיסים לפי סדר הרשימה (`Base1`, `Base2`), אחריהם השדות לפי סדר ההצהרה (`M2`, `M1`), ואז הגוף (`D`). רשימת האתחול `m1(), m2(), Base2(), Base1()` מתעלמת מהסדר שכתבתם. ההריסה הפוכה.

גלובלי, סטטי ומקומי:

```cpp
#include <iostream>
using namespace std;

struct T {
    int n;
    T(int n) : n(n) { cout << "+" << n << " "; }
    ~T() { cout << "-" << n << " "; }
};
T g1(1);                               // global: before main starts
void f() {
    T a(5);
    static T s(6);                     // built the first time control passes here
    T b(7);
}
int main() {
    cout << "main ";
    T l(2);
    static T s3(3);
    f();
    f();
    T m(4);
    cout << "\n";
}
```

```text
+1 main +2 +3 +5 +6 +7 -7 -5 +5 +7 -7 -5 +4 
-4 -2 -6 -3 -1 
```

- `+1` גלובלי לפני `main`.
- `main` מודפס, `+2` מקומי, `+3` סטטי של `main`.
- הקריאה הראשונה ל-`f`: `+5` (מקומי), `+6` (סטטי נבנה כעת), `+7`, ובסיום `-7 -5` (הסטטי נשאר).
- הקריאה השנייה: `+5 +7 -7 -5` ללא `+6`.
- `+4`, ואז בסוף `main`: `-4 -2` (מקומיים בסדר הפוך). לבסוף הסטטיים והגלובליים הפוך לבנייה: `-6 -3 -1`.

מערכים, זמניים ו-`new`:

```cpp
#include <iostream>
using namespace std;

struct T {
    int n;
    T(int n = 0) : n(n) { cout << "+" << n << " "; }
    ~T() { cout << "-" << n << " "; }
};
int counter = 0;
struct U {
    int id;
    U() : id(++counter) { cout << "U" << id << " "; }
    ~U() { cout << "~U" << id << " "; }
};
int main() {
    U arr[3];                          // constructed in index order, destroyed in reverse
    cout << "| ";
    T(8);                              // temporary: dies at the end of this statement
    cout << "| ";
    const T& r = T(9);                 // lifetime extended to the end of the scope
    cout << "| ";
    T* p = new T(10);                  // lives until delete
    cout << "| ";
    delete p;
    cout << "| end\n";
}
```

```text
U1 U2 U3 | +8 -8 | +9 | +10 | -10 | end
-9 ~U3 ~U2 ~U1 
```

הזמני `T(8)` נהרס מיד (`+8 -8`), ה-`T(9)` מוצמד להפניה ונהרס רק בסוף, אחרי `delete p`, ואחרי `end`, לפני המערך.

## מלכודות

> 🪤 **`delete` דרך מצביע לאב:** עם הורס וירטואלי נהרס קודם הנגזר ואז האב. בקריאה וירטואלית בתוך בנאי או הורס מופעל הסוג שנבנה כרגע:

```cpp
#include <iostream>
using namespace std;

struct B {
    B() { cout << "B() "; whoAmI(); }
    virtual ~B() { cout << "~B() "; whoAmI(); }
    virtual void whoAmI() { cout << "[B] "; }
};
struct D : B {
    D() { cout << "D() "; whoAmI(); }
    ~D() { cout << "~D() "; whoAmI(); }
    void whoAmI() { cout << "[D] "; }
};
int main() {
    B* p = new D;
    cout << "\n";
    delete p;                  // virtual destructor: D's part is destroyed first
    cout << "\n";
}
```

```text
B() [B] D() [D] 
~D() [D] ~B() [B] 
```

> 🪤 **בלי virtual** `delete p` על `p` שמצביע ל-`D` דרך `B*` הוא התנהגות לא מוגדרת. מפתחות המבחנים מניחים שרק ההורס של `B` רץ (`132`). בלי `delete` בכלל (18A-B שאלה 14), אין שום הרס:

```cpp
#include <iostream>
using namespace std;

struct B {
    B() { cout << "B "; }
    ~B() { cout << "~B "; }
};
struct D : B {
    D() { cout << "D "; }
    ~D() { cout << "~D "; }
};
int main() {
    B* p = new D;          // constructed as a whole D: B then D
    cout << "\n";
    D d;                   // a local D: B D ... ~D ~B
    cout << "\n";
    // delete p;           // would be undefined behaviour: ~B is not virtual (exam keys: prints only ~B)
}
```

```text
B D 
B D 
~D ~B 
```

> ⚠️ **רשימת האתחול לא קובעת סדר,** ושדה ללא בנאי ברירת מחדל חייב להופיע בה (ראו [[composition]]).

> ⚠️ **סטטי מקומי לא נבנה שוב** בקריאה שנייה, ולא נהרס בסוף הפונקציה.

> ⚠️ **העתקה מדפיסה בנאי העתקה, לא בנאי רגיל.** בשאלות על `A a1 = b1;` (22S-B שאלה 2) מודפס רק בנאי העתקה של `A`, בלי בנאי של `B`.
