# מחלקות, בנאים והורסים

> 🔑 **בשורה אחת:** בנאי רץ בכל יצירת אובייקט, הורס רץ בסוף חייו. הורס של אובייקט שנוצר ב-`new` רץ רק ב-`delete`. ברגע שכותבים בנאי כלשהו, הקומפיילר **מפסיק** לייצר בנאי ברירת מחדל.

## מה המבחן שואל

- אילו שורות בכלל יוצרות אובייקט: `X a;` כן, `X b();` לא (זו הצהרת פונקציה), `X c = X;` שגיאה, `X d = X();` כן (18A-A שאלה 4).
- מתי נקרא ההורס אחרי `A *a = new A;`: רק ב-`delete a` (19A-A שאלה 6).
- אילו פונקציות קיימות אוטומטית במחלקה ריקה: בנאי, בנאי העתקה, השמה, הורס, אבל לא `==` (19A-A שאלה 8).
- למה נחוץ `X(){}` לצד `X(int)`: כדי ש-`X x1;` וגם `new X[n]` יתקמפלו (22B-A שאלה 1).
- מה קורה כשכל הבנאים פרטיים: אין שגיאה בהגדרה, פשוט אי אפשר ליצור אובייקט מבחוץ (23B-B שאלה 15, 22B-A שאלה 14).
- הורס שמשחרר מערך שהוקצה בבנאי: מה מודפס כשהאובייקט עצמו לא נמחק (21B-B שאלה 4).
- אילו פונקציות לא יכולות להיות וירטואליות (בנאי) ואילו לא ניתנות להעמסה (הורס) (21B-B שאלות 9 ו-10).
- `Utest ut = Utest(20);` מדפיס פעם אחת (21B-B שאלה 11).
- הרשאות גישה לשדות פרטיים מתוך פונקציה חיצונית (19A-C שאלות 3 ו-9) וגטר שמחזיר `int&` או `int*` שפוגע בהסתרת המידע (23B-B שאלה 6).

## הגדרות

- **בנאי:** אותו שם כמו המחלקה, בלי טיפוס החזרה, אפשר להעמיס. **רשימת אתחול** `: x(1), y(2)` מאתחלת לפני גוף הבנאי.
- **הורס** `~X()`: בלי פרמטרים ולכן **יחיד** (אי אפשר להעמיס). רץ בסוף חיי אובייקט מקומי, בהריסת אובייקט גלובלי/סטטי, ב-`delete`.
- **נוצרים אוטומטית** (אם לא כתבתם): בנאי ברירת מחדל (רק אם אין שום בנאי אחר), בנאי העתקה, אופרטור השמה, הורס. אין `==` אוטומטי.
- **`new` ו-`delete`:** `new A` בנאי אחד, `delete p` הורס אחד. `new A[n]` n בנאים (חייב בנאי ברירת מחדל), ויש לשחרר ב-`delete[]`.
- **הרשאות:** `public` לכולם, `private` לחברי המחלקה ול-friend, ברירת המחדל ב-`class` היא `private`.

## מתכונים

**"האם נוצר אובייקט".** שורה עם סוגריים ריקים אחרי שם משתנה (`X b();`) היא הצהרת פונקציה. `X c = X;` לא חוקית כי `X` שם טיפוס ולא ערך.

**"מתי רץ ההורס".** אובייקט מקומי: בסוף הבלוק. `new`: רק ב-`delete`. אובייקט שמוחזק במצביע בתוך אובייקט אחר: רק אם ההורס של החיצון עושה `delete`.

**שגיאות גישה.** לכל שימוש בשדה שואלים: מי כותב (פונקציה של המחלקה, חיצונית, friend) ומה ההרשאה.

## דוגמה

```cpp
#include <iostream>
using namespace std;

struct X {
    X()  { cout << "ctor "; }
    ~X() { cout << "dtor "; }
};
int main() {
    X a;            // object
    X b();          // NOT an object: declares a function b returning X
    X d = X();      // one object (C++17: no extra temporary)
    cout << "end ";
}
```

```text
ctor ctor end dtor dtor 
```

`a` ו-`d` נוצרים (שני `ctor`), `b` לא יוצר אובייקט. אחרי `end` מופיעים שני הורסים. ההדפסה האחרונה בלי ירידת שורה היא חלק מהפלט.

מערכים ו-`new`:

```cpp
#include <iostream>
using namespace std;

struct A {
    int x;
    A(int x = 1) : x(x) {}
    ~A() { cout << x; }
};
int main() {
    A* arr = new A[3];       // three default-constructed objects
    delete[] arr;            // three destructor calls
    cout << "|";
    A* q = new A(7);         // no destructor yet
    cout << "|";
    delete q;                // now
    cout << "\n";
}
```

```text
111||7
```

`new A[3]` בונה שלושה אובייקטים עם `x=1`. `delete[]` מדפיס שלוש פעמים `1`. `new A(7)` לא מדפיס כלום בהריסה עד `delete q`.

## מלכודות

> 🪤 **בנאי כלשהו מבטל את בנאי ברירת המחדל.** אחרי שכתבנו `X(int)`, השורות `X x2;` ו-`X arr[2];` לא מתקמפלות. בנאי פרטי חוסם יצירה מבחוץ, אבל פונקציה סטטית של המחלקה עדיין יכולה ליצור:

```cpp
#include <iostream>
using namespace std;

struct X {
    int nx;
    X(int i) : nx(i) {}
};
class C {
    C() {}
public:
    static C make() { return C(); }
};
int main() {
    X x1(3);          // ok
    X x2;             // L1
    X arr[2];         // L2
    C c1;             // L3
    C c2 = C::make(); // ok
}
```

```text
L1: no matching constructor for initialization of 'X'
L2: no matching constructor for initialization of 'X[2]'
L3: calling a private constructor of class 'C'
```

> 🪤 **אין `==` אוטומטי,** ויש השמה והעתקה אוטומטיות:

```text
L1: invalid operands to binary expression ('A' and 'A')
```

> ⚠️ **ברירת המחדל ב-`class` היא פרטית,** וב-`struct` ציבורית:

```text
L1: 'v' is a private member of 'P'
```

> ⚠️ **אובייקט שהוקצה ב-`new` ולא נמחק לא קורא להורס שלו,** ולכן הזיכרון שהוא מחזיק בתוכו לא משתחרר (21B-B שאלה 4: מודפס כלום).

> ⚠️ **גטר שמחזיר הפניה או מצביע לשדה פרטי** פותח את השדה לשינוי מבחוץ. `int f()` בסדר, `int& g()` ו-`int* h()` נוגדות הסתרת מידע (23B-B שאלה 6).

> ⚠️ **`inline`:** פונקציה שמוגדרת בתוך גוף המחלקה היא `inline` באופן מרומז, ופונקציה שמוגדרת מחוץ למחלקה בלי המילה `inline` היא לא. `inline` היא בקשה לקומפיילר להטמיע את הגוף במקום הקריאה, והיא אינה משנה את ההתנהגות. אין לה קשר לקישור דינמי: קישור בזמן ריצה בא רק מ-`virtual` (22S-B שאלה 15, 25B-B שאלה 14).
